# 🏗️ Trueline Construction - Landing Page

A modern, high-performance, and fully responsive landing page designed and developed for a construction and renovation company. Built with focus on clean structure, industrial aesthetic, user experience (UX), and conversion optimization.

---

## 🌟 Key Features

- **Industrial Visual Aesthetic:** Styled with a custom construction-themed color palette (Slate Dark `#22303a`, Safety Orange `#e07a2c`, Warm Light `#f0ece4`) and modern typography (`Big Shoulders Display` and `Space Mono`).
- **100% Fully Responsive:** Developed using **Bootstrap 5** framework with custom CSS, ensuring a seamless experience across Mobile, Tablet, and Desktop screens.
- **Architectural & Blueprint Graphics:** Custom dimension/blueprint lines and crisp inline SVG icons integrated directly into the layout.
- **Conversion-Oriented Sections:**
  - **Hero Section:** Clear value proposition with primary and secondary CTAs.
  - **Trust Strip & Key Metrics:** Highlighting statistics, guarantee points, and company performance.
  - **Service & Portfolio Showcases:** Clean card grids displaying core services and featured projects.
  - **Client Testimonials:** Social proof section with rating stars.
  - **Estimate Request Form:** Modern form UI optimized for high response rates.
- **Smooth Navigation:** Sticky header with fast-scrolling page links.

---

## 🛠️ Tech Stack & Tools

- **HTML5:** Semantic markup for optimal SEO and accessibility.
- **CSS3:** Custom styles, CSS variables, dynamic animations, and responsive media queries.
- **Bootstrap 5:** Layout grid system and core UI components.
- **SVG:** Inline vector icons and custom graphics.
